# Asma Ahmed Portfolio — 2026 Refresh

A recruiter-focused React/Vite portfolio with a purple-glow visual system, animated background, interactive project vault, experience timeline, awards, credentials and leadership highlights.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production-ready static build is generated in `dist/`.

## Stack

- React 18 + Vite
- Framer Motion
- CSS + Framer Motion animated background
- Lucide icons
- Tailwind base utilities + custom CSS

## Content strategy

The homepage prioritizes recruiter-relevant work in software engineering, AI/ML, cloud, GIS/geospatial systems and technology consulting. The searchable Project Vault retains the broader project history and original portfolio projects without overwhelming the initial scan.
